# devops-capstone-project

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![Python 3.9](https://img.shields.io/badge/Python-3.9-green.svg)](https://shields.io/)

This DevOps capstone project implements and delivers a customer accounts microservice for an e-commerce application. The project covers REST API development, automated testing, containerization with Docker, and deployment to Kubernetes using DevOps practices.

The service manages customer account information such as names, email addresses, physical addresses, phone numbers, and join dates. The capstone work includes completing the account CRUD and list operations while maintaining strong test coverage, then packaging and deploying the service through a repeatable delivery workflow.

## Project goals

- Set up a productive development environment.
- Implement and test account read, update, delete, and list operations.
- Build a Docker image for the microservice.
- Deploy the containerized service to Kubernetes.
- Practice agile planning with user stories, a product backlog, and sprint planning.

## Usage

This repository contains the starter code and supporting files for the IBM DevOps Capstone Project. See the existing project documentation and Makefile targets for development, testing, Docker, and Kubernetes workflows.
